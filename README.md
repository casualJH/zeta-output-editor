# 제타 출력 보정

Gemini API를 이용해 제타(Zeta) 채팅의 대사와 지문을 자연스럽게 보완하는 Tampermonkey 유저스크립트입니다.

## 설치 및 업데이트

1. 브라우저에 **Tampermonkey**를 설치합니다.
2. **[제타 출력 보정 설치하기](https://raw.githubusercontent.com/casualJH/zeta-output-editor/main/zeta-output-editor.user.js)**를 열어 스크립트를 설치합니다.
3. 제타 채팅방을 새로고침합니다.

스크립트 업데이트는 Tampermonkey의 업데이트 확인 기능을 이용할 수 있습니다.

## 주요 기능

- Gemini API로 대사·지문의 문장 흐름, 묘사, 감정선을 보정
- 제타 원문의 화자 표식(`@이름:`, `@:`)과 지문 형식(`*지문*`) 유지
- 원문과 수정본 확인, 수정본 복사 및 재시도
- 제타 수정창에서 원문 가져오기, 수정본 덮어쓰기 및 저장
- API 키·모델·보정 지침 설정
- 드래그 가능한 실행 버튼과 팝업창, 크기 조절 및 화면 모드 설정

## 사용 방법

1. 제타 채팅방에서 **출력 보정** 버튼을 누릅니다.
2. **설정**에서 Gemini API 키를 입력하고 저장합니다.
3. **수정창에서 가져오기**를 사용하거나 원문을 직접 붙여넣습니다.
4. **보정 실행**을 누르고 수정본을 확인합니다.
5. **수정본 복사** 또는 **수정창에 덮어쓰기**를 사용합니다. 저장까지 원하면 **수정창에 덮어쓰고 저장**을 선택합니다.

## 참고 사항

- Gemini API 키가 필요하며, API 이용 한도나 요금은 Google의 정책을 따릅니다.
- 보정 결과는 AI가 생성하므로 **저장 전 내용을 확인**하세요.
- 프레임 연결이 되지 않는 경우 Tampermonkey에서 `frame.pingpong.ai` 사이트 접근 권한을 확인하세요.
